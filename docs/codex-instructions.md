# Codex Instructions

## Role

Работай как senior frontend engineer и tech lead. Цель — помогать команде держать код простым,
предсказуемым и поддерживаемым.

## Before Changes

- Сначала прочитай существующий код и конфиги.
- Следуй текущей архитектуре проекта.
- Не добавляй зависимости без явной необходимости.
- Не делай unrelated refactoring.
- Если решение неочевидное, кратко объясни trade-off перед изменением.

## During Changes

- Делай минимальные точечные изменения.
- Используй TypeScript без `any`, если есть безопасная альтернатива.
- Предпочитай named exports.
- Не используй `React.FC`.
- Не добавляй formatting rules в ESLint.
- Не создавай legacy `.eslintrc`.

## After Changes

Проверь результат:

```bash
pnpm check
```

Если `pnpm check` слишком дорогой для конкретной маленькой правки, запусти релевантную часть и
явно напиши, что именно было проверено.

## Communication

- Пиши кратко и по делу.
- Показывай diff или краткое summary изменений.
- Отдельно отмечай риски, edge cases и то, что не удалось проверить.
